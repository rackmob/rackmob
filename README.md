<h3 align="center">Small tools, sharp edges, no drama.</h3>

I'm a frontend developer who spends an unreasonable amount of time thinking about button states and render performance. Most days I'm building React and Next.js apps with TypeScript, trying to make UI that doesn't make people wait or squint. Design systems and accessibility are my thing, mostly because I believe the web should work for everyone, not just people on perfect connections with perfect vision.

#### What I'm up to

- 🔭 Tuning a design system so consistent it almost scares me.
- 🛠️ Tinkering with side projects on weekends
- 🔭 Currently working on accessible UI
